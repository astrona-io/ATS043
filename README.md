# Kubernetes Security Fundamentals (ATS043)

Kubernetes and Cloud Native Associate (KCSA) — Kubernetes Security Fundamentals, 22% of the published curriculum. This course is part of ATP009.

Concept lessons, playgrounds, graded labs, capstones and quizzes cover each official objective with concrete examples, diagrams and scenario reasoning. Every section begins with an introduction, and every module ends with a summary. Reusable YAML question banks include the correct answer, option feedback and learning-objective mapping.

## Authoring Status

Each section has a module with a playground and a graded lab, a capstone lab and a `quiz.yaml`. Labs and playgrounds are UNTESTED (static checks only). A kind cluster is needed to do them. Technical sections and the ATP009 registration remain draft until the maintainer approves publication.
