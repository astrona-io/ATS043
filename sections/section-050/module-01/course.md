# Secret Delivery And Credential Lifecycle

This module develops the reasoning needed to explain why Secret encoding is not encryption.

## Learning Goals

- Explain why Secret encoding is not encryption.
- Compare environment and mounted-file update behavior.
- Identify authorization and diagnostic exposure risks.
- Describe rotation that updates consumers and revokes old authority.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
