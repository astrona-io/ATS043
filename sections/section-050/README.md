# Secrets

This section teaches secret delivery and credential lifecycle. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Secret Delivery And Credential Lifecycle. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain why Secret encoding is not encryption.
- Compare environment and mounted-file update behavior.
- Identify authorization and diagnostic exposure risks.
- Describe rotation that updates consumers and revokes old authority.
