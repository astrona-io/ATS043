# Audit Logging

This section teaches audit policy and security evidence. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Audit Policy And Security Evidence. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain what Kubernetes audit events record.
- Compare Metadata, Request and RequestResponse audit detail.
- Relate audit retention and protection to investigation.
- Distinguish API evidence from runtime and application evidence.
