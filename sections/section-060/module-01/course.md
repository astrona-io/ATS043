# Isolation And Namespace Segmentation

This module develops the reasoning needed to distinguish namespace scope from physical or kernel isolation.

## Learning Goals

- Distinguish namespace scope from physical or kernel isolation.
- Compare API, network, process and resource controls.
- Relate shared-node trust to workload compromise.
- Identify residual access through legitimate dependencies.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
