# Summary

Namespace scoping organizes selected API permissions and policy but does not automatically create network or kernel isolation. Process restrictions, connection controls and resource budgets address distinct boundaries.

Shared management, nodes and dependencies remain within the trust model. Evaluate what a compromised workload can do through both unnecessary authority and legitimate application access, then choose stronger boundaries where the consequence requires them.
