# Authentication And Workload Credentials

This module develops the reasoning needed to distinguish established identity from granted API permission.

## Learning Goals

- Distinguish established identity from granted API permission.
- Explain ServiceAccount token audience and lifetime.
- Identify unnecessary credential mounting and disclosure paths.
- Relate authentication failure to the actual credential mechanism.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
