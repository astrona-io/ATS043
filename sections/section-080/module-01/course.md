# NetworkPolicy Semantics And Verification

This module develops the reasoning needed to explain Pod selection and direction-specific network isolation.

## Learning Goals

- Explain Pod selection and direction-specific network isolation.
- Evaluate additive allowed rules and selector structure.
- Relate DNS and dependencies to egress requirements.
- Distinguish declared policy from actual implementation enforcement.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
