# Pod Security Admission Decisions

This module develops the reasoning needed to distinguish enforce, warn and audit policy modes.

## Learning Goals

- Distinguish enforce, warn and audit policy modes.
- Explain namespace policy labels and version selection.
- Predict the effect of policy changes on new workload Pods.
- Separate Pod Security Admission from RBAC and image verification.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
