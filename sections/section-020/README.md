# Pod Security Admissions

This section teaches pod security admission decisions. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Pod Security Admission Decisions. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Distinguish enforce, warn and audit policy modes.
- Explain namespace policy labels and version selection.
- Predict the effect of policy changes on new workload Pods.
- Separate Pod Security Admission from RBAC and image verification.
