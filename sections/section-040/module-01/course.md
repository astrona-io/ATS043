# Authorization And Effective Permissions

This module develops the reasoning needed to compare Role, ClusterRole, RoleBinding and ClusterRoleBinding.

## Learning Goals

- Compare Role, ClusterRole, RoleBinding and ClusterRoleBinding.
- Evaluate namespace scope, verbs, resources and subjects.
- Explain additive grants and indirect privilege.
- Apply least privilege to a workload identity.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
