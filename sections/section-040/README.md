# Authorization

This section teaches authorization and effective permissions. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Authorization And Effective Permissions. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Compare Role, ClusterRole, RoleBinding and ClusterRoleBinding.
- Evaluate namespace scope, verbs, resources and subjects.
- Explain additive grants and indirect privilege.
- Apply least privilege to a workload identity.
