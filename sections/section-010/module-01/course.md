# Pod Security Profiles

This module develops the reasoning needed to compare Privileged, Baseline and Restricted profiles.

## Learning Goals

- Compare Privileged, Baseline and Restricted profiles.
- Explain the purpose and limits of security-context fields.
- Relate image users and writable paths to profile compatibility.
- Distinguish compliant configuration from complete application security.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
